# Joining the reading club (for friends)

You don't need to install anything. The club runs in your web browser (Chrome, Edge, Firefox or Safari, on a phone or computer).

## 1. Get the address and code from the host

The host sends you:

* an **address**:
  * from anywhere: an online link like `https://some-random-words.trycloudflare.com`;
  * on the host's Wi-Fi: something like `http://192.168.1.20:8765`;
* an **invitation code**, for example `K7PM4XQ2`, or a ready-made invitation link that already contains it.

The free online link changes whenever the host restarts sharing. If it stops working, ask for the new one; your account stays the same.

## 2. Tailscale (only if your host uses it)

Some hosts use Tailscale instead of the online link. In that case:

1. Install Tailscale (<https://tailscale.com/download>).
2. Accept the host's invitation and make sure Tailscale shows **Connected**.
3. Use the `100.x.y.z` address the host gave you.

## 3. Create your account

Open the address, click **I have an invitation code**, and choose a username, display name and password.
You can also open the invitation link directly. Then add the page to your home screen or bookmarks.

## 4. Daily reading

* **Group** shows the shared streak, who has finished today, and the time left before the day resets.
* **Read** opens the Quran at your bookmark.
  * **Flow** mode: the text flows like an e-book. A small ornament with a number marks the end of each standard mushaf page. Juz and hizb markers sit in the side margin.
  * **Mushaf** mode: one standard page at a time.
  * Use **−/+** (or the − and + keys) for text size and ☀/☾ for the night or paper theme. Press **F** for fullscreen.
    **← / →** or the buttons turn pages; Arabic reads right to left, so ← is the next page.
* The bar at the top shows today's active time and pages, plus how many seconds until the current page counts.
* **Me** shows your streaks, totals, khatma map, calendar and history.

## 5. Things to know

* The timer only runs while the reader is **on screen, focused and in use**. It pauses if you switch apps or tabs, or after about a minute without touching anything.
  While reading a long page, a small scroll or tap keeps it running.
* A page counts once it has had about 20 seconds of reading. Re-reading pages you've already counted doesn't add pages.
* Only one device can read at a time. Opening the reader on your phone pauses it on your laptop.
* The group streak grows only when **everyone** finishes the day's minimum (by default 2 pages **and** 20 minutes).
